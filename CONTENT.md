# Как обновлять цены и масла

После любого изменения выполните `npm run build` для публикационной сборки или оставьте запущенным `npm run dev` во время редактирования.

## Цены на работы и шиномонтаж

Откройте [src/data/services.json](src/data/services.json).

- В `oilChangePrices` одна строка — одна услуга: `name`, `price`, `note`.
- В `tirePrices` одна строка — один диаметр: `diameter`, `passenger`, `crossoverMinivan`.

## Масла

Откройте [src/data/oils.json](src/data/oils.json). У каждой позиции есть:

- `name` — название;
- `price` — цена;
- `description` — короткое описание на карточке;
- `specifications` — текст, который раскрывается по кнопке «Характеристики». Оставьте пустую строку, чтобы эту кнопку не показывать.

Сохраняйте JSON: текстовые значения заключаются в двойные кавычки, а между объектами ставится запятая.
